# Foto produk

Taruh foto produk di folder ini dengan nama file sesuai `photos` di data contoh, misalnya:

- `night-ride-tee-1.jpg`
- `ashfall-tee-1.jpg`
- `hollow-crown-tee-1.jpg`
- `static-choir-tee-1.jpg`
- `ashfall-long-sleeve-1.jpg`
- `ashen-logo-tee-1.jpg`
- `cinder-sigil-long-sleeve-1.jpg`
- `rider-leather-jacket-1.jpg`

Akhiran `-1` untuk foto depan dan `-2` untuk foto belakang/detail.

Gunakan foto persegi (misalnya 1080×1080). Selama file belum ada, website menampilkan placeholder gelap.
